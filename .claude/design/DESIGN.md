# DESIGN — jtwjs-desk 스타일 정본

> 스타일만 적는다. 화면 이름 · 데이터는 `brief.md`에 있다. 작성일 2026-11-11. 상태: **초안(Finn 검토 전)**.
> 값에 붙은 표식: **측정**(레퍼런스 이미지에서 읽음) · **계산**(공식으로 계산) · **제안**(AI가 정한 값, 검증 전) · `미측정`.

## 0. 기준과 바꾼 것

- **복제 원본**: Better Stack의 다크 앱 셸(레퍼런스 이미지 2장, `references/README.md`). 구조 + 다크 톤을 따른다.
- **형식 틀**: `references/DESIGN-mobbin.md`의 절 구성(색 · 타입 · 반경 · 간격 · 컴포넌트 · Do/Don't)과 컴포넌트 이름만 쓴다. 라이트 팔레트 · 알약 컨트롤 · 마케팅 요소는 안 쓴다.
- **바꾼 것(원본과 다른 점)**
  - 아이콘 레일(제품 전환용 별도 컬럼) 없음. 메뉴 패널 한 단만 두되 **항목마다 선 아이콘을 둔다**(Finn 결정, 2026-11-11). 접으면 같은 패널이 아이콘만 남는 좁은 폭이 된다
  - 글꼴은 Pretendard
  - 상태색은 기준 세트(Tailwind v3.4.17 400 단계) + 브랜드 인디고 — Better Stack의 상태색은 공식 값이 없어 못 따른다
  - 차트(도넛 · 히스토그램) 없음
  - 목록 행은 여러 줄을 허용한다(Finn 결정)

## 1. 원칙 (Principles)

1. **톤으로 계층을 만든다.** 그림자가 없다. 바탕 세 단과 한 단 밝은 구분선으로 위아래를 나눈다.
2. **상태가 본업이다.** 색 하나만으로 뜻을 전하지 않는다. 항상 점(또는 모양) + 한국어 라벨 + 의미색을 같이 쓴다. 한 행에는 의미색 하나만 쓴다.
3. **인디고는 선택 · 진행에만 쓴다.** 장식에 쓰지 않는다. 사람이 움직일 차례는 amber다.
4. **훑고, 필요하면 읽는다.** 표는 조밀하고, 긴 글은 줄을 이어 보인다. 고정폭 글꼴은 ID · 경로 · 브랜치에만 쓴다.
5. **조용히 비어 보이지 않는다.** 빈 곳에는 이유를 한 줄로 쓴다.

## 2. 색 (Color)

### 바탕 · 구분선 (측정, 무손실 PNG 기준값)

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `surface-content` | `#202432` | 본문 영역 · 표 행 바탕 |
| `surface-panel` | `#232837` | 메뉴 패널 · 상단 바 · 칩 · 표 헤더 |
| `surface-raised` | `#2A303F` | 선택된 메뉴 항목 · 입력 · 버튼 · **구분선** |

요약 카드 안쪽은 `surface-content`와 같다. 카드는 톤이 아니라 테두리(`surface-raised`)로 구분한다. 로고 색 `#0B0C14`는 UI 바탕이 아니다.

### 글자 (측정 + 계산)

| 토큰 | 값 | 대비(content / panel / raised) | 쓰는 곳 |
|---|---|---|---|
| `text-strong` | `#FFFFFF` | 15.44 / 14.68 / 13.18 | 제목 · 메뉴 라벨 · 올림면 위 글자 |
| `text-body` | `#B9BFCF` | 8.40 / 7.98 / 7.17 | 본문 · 표 셀 |
| `text-muted` | `#959DB6` | 5.72 / 5.44 / 4.88 | 표 헤더 · 설명 · 보조 |

레퍼런스의 `#656D84`(축 숫자)는 대비 3.00 / 2.85 / 2.56이라 desk에서 쓰지 않는다.

### 의미색 (계산)

| 역할 | 값(Tailwind v3.4.17) | content | panel | raised |
|---|---|---|---|---|
| 선택 · 진행 `accent` | `#7C87F7`(브랜드) | 4.90 | 4.66 | **4.18** |
| 사람 차례 · 주의 `attention` | `#FBBF24`(amber-400) | 9.25 | 8.80 | 7.90 |
| 정상 · 완료 `success` | `#34D399`(emerald-400) | 8.03 | 7.64 | 6.86 |
| 오류 · 막힘 `danger` | `#F87171`(red-400) | 5.58 | 5.31 | 4.77 |
| 중립 · 비활성 `neutral` | `#94A3B8`(slate-400) | 6.02 | 5.73 | 5.14 |

규칙:
- `accent`는 올림면(`surface-raised`) 위 작은 글자에서 4.5 미만이다. **올림면 위에서는 글자를 `text-strong`으로 두고** `accent`는 점 · 막대 · 큰 글자에만 쓴다
- 브랜드 `#5B63D3`은 글자 · 선에 쓰지 않는다(바탕 위 3.07 / 2.92 / 2.62). **채움 면**에만 쓰고, 그 위 글자는 `#FFFFFF`(5.04)
- slate-500은 구분선으로 쓰지 않는다(올림면 위 2.77). 구분선은 `surface-raised`
- 틴트는 카드 · 안내 줄 안에서만 쓰고, 표 행의 상태 라벨은 틴트 없이 점 + 라벨만 쓴다(훑기 위해)
- 칩 틴트(같은 색의 낮은 투명도 배경): 글자 대비를 계산해 정한 상한이다. `attention` · `success` · `neutral`은 10%까지, `danger`는 10%까지(content 위 4.82, panel 위 4.62), **`accent`는 틴트 위에 글자를 얹지 않는다**(6%에서도 panel 위 4.27). 인디고 상태는 점 + `text-strong` 라벨 + 틴트 없음
- 점수 등급 색(Finn 결정): 채점 도구가 주는 색 이름을 그대로 옮긴다. green → `success`, amber → `attention`, red → `danger`. 등급 배지는 점 + 라벨 + 10% 틴트. 등급 이름(`AI-Native` · `AI-Ready` · `AI-Assisted` · `AI-Fragile` · `AI-Hostile`)은 영어 원문 그대로, 한국어 병기는 미정. 구간 숫자는 채점 도구 버전에 따라 달라질 수 있어 desk는 데이터가 주는 등급 · 색을 쓴다

## 3. 타이포그래피 (Typography)

- **본문 글꼴: Pretendard**(Finn 결정). 라이선스 SIL OFL 1.1, 최신 릴리스 v1.3.9, 전체 패키지 zip 47,304,526바이트(GitHub 릴리스 목록에서 확인함). **레포에 포함**한다(Finn 결정, 오프라인 동작). 쓸 파일은 한글 포함 가변 웨이트 woff2 하나이고 용량은 `미측정`(받아서 잰 뒤 `DESIGN.md`에 기록). 라이선스 파일 사본을 글꼴 옆에 둔다
- **고정폭**: 시스템 고정폭 스택. ID · 경로 · 브랜치에만 쓴다
- **크기 · 굵기 · 줄간격(제안, 구현 뒤 화면에서 검증)**: 제목 20 / 600 · 본문 14 / 400 · 표 셀 13 / 400 · 표 헤더 12 / 500 · 라벨 12 / 500. 줄간격은 본문 1.5, 여러 줄 행 1.4
- 한글은 `word-break: keep-all`로 단어 중간에서 끊지 않는다

## 4. 모양 · 간격 · 깊이 (제안)

- 레퍼런스 이미지는 확대 배율을 알 수 없어 **CSS px로 환산하지 못했다**(`미측정`: 이미지에서 읽은 비율은 `references/README.md` 측정 기록). 아래 값은 제안이고 구현 화면에서 검증한다
- 간격은 4 기준 배수(4 · 8 · 12 · 16 · 24 · 32)
- 반경: 컨트롤(입력 · 버튼 · 칩) 6, 카드 · 패널 8. 알약 모양은 쓰지 않는다
- 깊이: 그림자 없음. 구분은 톤 차이와 1 두께 선(`surface-raised`)
- 메뉴 패널 폭 · 접은 폭 · 행 높이 · 칩 높이: `미측정`, 구현 화면에서 정하고 이 문서에 되적는다

## 5. 컴포넌트 (이름은 Mobbin 문서 참고, 모양은 이 문서가 정한다)

| 이름 | 모양 |
|---|---|
| `app-shell` | 왼쪽 메뉴 패널(`surface-panel`) + 본문(`surface-content`). 패널과 본문 사이 선 하나 |
| `shell-nav-item` | 선 아이콘 + 라벨(아이콘은 stroke 2, 기본 `text-muted`, 선택은 `text-strong`). 평소 라벨 `text-body`, 선택은 `surface-raised` 면 + `text-strong`. 그룹 부모는 아래 화살표, 하위는 아이콘 없이 들여쓰기 + 왼쪽 가는 세로선. 패널 제목 옆에 접기 버튼. **접은 상태**: 아이콘만 가운데 정렬, 가리키거나 포커스하면 `tooltip`으로 이름, 3역량 하위는 펼친 상태에서만 보인다. 접은 상태에서 3역량 아이콘을 누르면 메뉴가 펼쳐지고 그룹도 펼쳐진다(Finn 결정). 하위 항목이 선택되면 선택 면은 그 하위 항목 하나뿐이고 부모는 면 없이 라벨 · 아이콘만 `text-strong`이다(Finn 결정). **판정 · 복습함 항목에만 대기 건수**를 오른쪽에 `attention` 글자 숫자로 단다(틴트 없음, Finn 결정). 접은 상태에서는 아이콘 모서리의 `attention` 점으로 바꾼다(제안). 접은 폭은 `미측정`(캔버스 견본은 64, 제안) |
| `status-dot-label` | 점 + 한국어 라벨, 둘 다 의미색. 줄 맨 앞에 둔다 |
| `chip` | `surface-panel` 면 + 테두리, `라벨 | 값 ⌄`. 필요한 곳에만 한 줄 |
| `data-table` | 헤더 `surface-panel` + `text-muted`, 열 이름은 말줄임. 행 구분선, 행은 여러 줄 허용, 셀은 `text-body` |
| `kpi-tile` | 테두리 카드, 큰 숫자 `text-strong` + 라벨 `text-muted` + (있으면) 증감. 증감이 없으면 자리째 숨긴다. 증감 색(Finn 결정): 막힌 것이 늘면 `danger`, 줄면 `success`, 그 밖의 증감은 색 없이 `text-muted` |
| `decision-card` | 테두리 카드. 머리에 제목 + 레포 · 브랜치(고정폭) + 오른쪽 위 상태 라벨. 선택지 목록(선택은 `surface-raised` 면 + `accent` 테두리 · 점, 추천은 `text-muted` 글자), `직접 쓰기` 선택 시 입력칸, 반영 버튼. 반영 전에는 다시 고를 수 있고, 반영 뒤에는 선택지와 버튼을 없애고 잠금 문장만 둔다 |
| `empty-state-card` | 테두리 카드, 이유 한 줄 + 다음에 할 일 한 줄. 의미색 점 하나 |
| `inline-note` | 화면 위 한 줄 안내(설정 · 폴백 · 미등록). `neutral` 또는 `attention` |
| `wait-line` | 표 아래 가운데 한 줄 대기 문구, `text-body` |
| `tooltip` | 잘린 열 이름의 전체 이름. `surface-raised` 면 |
| `button` | 기본: `surface-raised` 면 + `text-strong`. 강조: 브랜드 `#5B63D3` 채움 + `#FFFFFF` 글자. 위험 동작은 `danger`가 아니라 확인 단계를 둔다. 글자는 버튼 안 가운데 정렬. 표 행 안에서는 높이를 줄인 작은 버튼을 쓴다(화면 보드 견본은 28, 일반은 36 · 제안, 실렌더에서 확인) |
| `focus-ring` | `accent` 2 두께 바깥선(제안). 모든 조작 요소에 |

## 6. 상태 (States)

- **로딩**: 표는 헤더를 먼저 그리고 아래에 `wait-line`. 스켈레톤을 쓰지 않는다(폴링 갱신이 깜빡이면 안 된다)
- **빈**: `empty-state-card`. 이유를 말한다("대기 중인 항목 없음"처럼 사실만)
- **에러**: 목록은 마지막 정상 값을 유지하고 화면 위에 `danger` 한 줄. 카드 안 저장 실패는 그 카드 안에 이유 한 줄, 입력은 유지
- **missing**(경로 없음 · 파일 없음 · 형식 확인 필요 · 채점 없음): 행을 숨기지 않고 `neutral`(없음) 또는 `attention`(형식 확인 필요) 점 + 라벨
- **비활성**: 글자를 `text-muted`로 낮추고 점을 `neutral`로. 이유를 툴팁이 아니라 같은 줄에 쓴다
- **hover**(Finn 결정): 새 색 없이 기존 토큰만. 메뉴 항목 · 표 행은 `surface-raised` 50% 투명 면(+ 메뉴는 아이콘 · 글자 `text-strong`), 선택은 불투명 면 + 굵기 500. 버튼은 색을 바꾸지 않고 1 두께 테두리(기본 버튼 `text-muted`, 강조 버튼 `accent`)
- **포커스**: 항상 보인다. 키보드 이동 순서는 위→아래, 메뉴→본문

## 7. 모션 (Motion)

움직임은 상태 변화를 알리는 데만 쓴다. 색 · 배경 전환 150ms 이내(제안), 이동 · 크기 애니메이션 없음. 메뉴 그룹 펼침과 접기는 즉시 또는 150ms 이내 높이 변화 한 가지만 쓴다. `prefers-reduced-motion`이면 전부 끈다. 폴링 갱신은 값만 바꾸고 흔들리지 않는다.

## 8. Do / Don't

| Do | Don't |
|---|---|
| 점 + 라벨 + 의미색을 같이 | 색만으로 상태 표기 |
| 올림면 위 글자는 `text-strong` | 올림면 위에 `accent` 작은 글자 |
| 구분선은 `surface-raised` | 그림자 · slate-500 선 · `#656D84` 글자 |
| 인디고는 선택 · 진행만 | 인디고를 장식 · 링크 외 용도로 번지게 |
| 한 행에 의미색 하나 | 한 행에 의미색 둘 이상 |
| 고정폭은 ID · 경로에만 | 본문 전체를 고정폭으로 |
| 인디고 상태는 틴트 없이 | 인디고 틴트 위 글자 |

## 9. 확인 구분

- **확인함**: 바탕 · 글자 · 강조 값(이미지 2장 측정, WebP는 ±3), 대비 값(공식으로 계산), 의미색 hex(Tailwind v3.4.17 문서에서 읽음), Pretendard 라이선스 · 릴리스 · 용량(GitHub)
- **제안(검증 전)**: 크기 스케일 · 간격 · 반경 · 모션 시간 · 포커스 링 · 칩 틴트 비율
- **미측정**: 글꼴 파일 용량(받아서 잼) · 패널 폭 · 행 높이 · 칩 높이(구현 화면에서)
