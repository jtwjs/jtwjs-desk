# 브리프: 칸반 (desk-kanban)

> 상태: 승인(2026-11-14, Finn 채팅 「그려줘」). 색·서체·치수는 쓰지 않는다(`DESIGN.md` 토큰 재사용). 근거는 `docs/desk-kanban-2026-11-14/PRD.md` · `ARCHITECTURE.md` · `ADR.md`. 캔버스는 승인 뒤 그렸다.

## 레퍼런스

찾아본 것(검색 요약, 화면을 직접 열어 보지는 않음): GitHub Projects(카드 제목 클릭 시 우측 패널, 새 탭 링크), Jira 보드(패널 또는 모달, 설정으로 선택), Linear(Space 키 peek), Fibery·GitLab(패널/전체 페이지 토글). 공통점은 가벼운 미리보기가 기본이라는 것.
가져온 것: 카드를 누르면 우측 패널. 가져오지 않은 것: 상시 고정 패널, 드래그 이동, 담당자·라벨 같은 팀 기능(사용자는 Finn 한 명).
스타일은 기존 desk 셸(`DESIGN.md`)을 그대로 쓴다.

## 화면 목적

예정부터 merge까지 카드를 한 화면에서 보고, 예정 카드에서 지휘 세션으로 작업 시작 요청을 넘긴다. 사용자는 Finn 한 명(지휘 세션이 항상 켜져 있다는 전제), 진입은 좌측 메뉴 「칸반」(트랙과 별개).

## 화면 · 뷰포트

화면 하나(보드) + 두 개의 겹침(우측 세부 패널, 새 카드 모달) + 「보관 보기」 상태. 데스크톱만. 좁은 창은 보드가 가로 스크롤(열 폭 고정, 최소 폭은 시안에서 정함). 폰은 범위 밖.

## 구성 (ASCII 개략)

```
 칸반              [레포 | 전체 ⌄] [기간 | 전체 ⌄] │ [보관 보기] [+ 새 카드]
 ⚠ 읽지 못한 카드 N개                  ← 0이면 줄 없음
┌ 예정 (3) ──────┐ ┌ 진행 (4) ─────────┐ ┌ 완료 (12) ────┐
│ [a] 로그 정리   │ │ 🔶 PR 대기 [b] 배포│ │ [a] 문서 정리 │
│ [b] 알림 점검   │ │ 3일                │ │ [b] ...       │
│ [a] ...         │ │ ⚠ step 전부 끝남   │ │ (최근 5개)    │
│                 │ │   · PR 대기 후보   │ │ 더 보기 (7)   │
│                 │ │ [a] ⏳ 요청됨      │ │               │
│                 │ │ [a] 설계 중  2일   │ │               │
│                 │ │ [b] 6/9 · 5일      │ │               │
└─────────────────┘ └────────────────────┘ └───────────────┘
```

카드 한 장: 레포 이름표 · 제목(두 줄까지) · 상태 표식(⏳요청됨 / 🔶PR 대기 / ⚠후보 / 설계 중 / 연결 끊김) · 진행도(완료 step/전체) · 경과 일수.

패널(카드를 눌렀을 때만 열림):
```
┌ 세부 ─────────────── ✕ ┐
│ 로그 정리 (a)           │
│ 메모 …                  │
│ 날짜: 생성·요청·진행…   │
│ step 목록 + summary     │
│ [▶ 작업 시작] [보관/삭제]│
└─────────────────────────┘
```

새 카드 모달:
```
┌ 새 카드 ────────────────┐
│ 레포(필수)  [▼ 선택…  ] │
│ 제목(필수)  [           ] │
│ 메모        [           ] │
│ ⓘ 사람 이름·원문은 쓰지 마세요 │
│ 비어 있는 칸: 레포 · 제목 │
│          [취소] [추가 ░░] │
└─────────────────────────┘
```

## 데이터 · 권한 · 폼

- 데이터: `GET /board`(레포 전체, `?archived=1`, 필터는 `repo`·`from`·`to`를 서버가 적용하고 열별 전체 건수를 함께 준다), 카드를 누를 때 `GET /board/card?repo=&id=`. 보이는 탭만 15초 폴링(ADR-010). 쓰기는 `POST /board/add|delete|archive|revive|start`(기존 POST 가드)
- 권한: 없음(Finn 한 명). 열 이동·PR 대기 표시·task 기록은 화면에 없고 지휘 세션이 `desk.py`로 한다
- 폼: 새 카드 모달 하나(레포 · 제목 · 메모). 서버도 빈 제목·모르는 레포를 거절한다
- 기존 기능과의 관계: 신규 메뉴. 트랙·`/nav-counts`·기존 응답은 건드리지 않음. 사이드 메뉴에 숫자 배지 없음

## 재사용 후보

`page/index.html`의 `inlineNote(…, "danger")`(실패 줄), `chip(label,value)` 계열 필터(레포 칩 선례는 트랙·풀스택 탭). 검색 셀렉트·데이트피커는 신규 컴포넌트 후보, 메뉴 항목 마크업, 기존 카드 마크업. 코드 이름은 구현 때 `design-system-map`에서 확정. 확정 아님.

## 제약

- 외부 패키지 없음, 응답 문자열은 `textContent`로만
- 색만으로 뜻을 전하지 않는다(라벨 + 점/모양 병기). 한 행에 의미색은 하나
- CRITICAL: 사람 이름 · vault 원문 · 세션 원문을 카드·화면·상태 파일에 넣지 않는다(모달 안내 문구)
- 서버가 집계하는 목록을 화면이 `slice`로 자르지 않는다(완료 열은 서버가 자르고 전체 건수를 줌)
- `prefers-reduced-motion`이면 패널 슬라이드 없음
